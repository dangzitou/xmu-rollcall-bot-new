# XMU Rollcall Bot

Tools for monitoring and handling XMU roll-call notifications.

For installation and usage of the packaged CLI, see the [CLI guide](xmu-rollcall-cli/README.md). The repository also includes standalone monitoring scripts under `scripts/`.

See [`CHANGELOG.md`](CHANGELOG.md) for recent fixes and maintenance updates. Contributions should include focused changes, relevant verification, and a concise changelog entry when behavior changes.
